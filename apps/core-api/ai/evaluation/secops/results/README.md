# SecOps 실험 요약

#380 이후 저장 근거로 측정한 1–9차와 #583 2단계의 10–19차 목적·규모·당시 결과를 정리한다. 결함별 수정 근거는 [품질 개선 근거](../defects.md), 현재 규격은 [품질 기준](../baseline.md)에서 확인한다. 모델은 모두 `gpt-5.6-luna / low`이며, 표의 결과는 구조화 값과 의미 검토를 합친 건별 판정이다. 라운드마다 측정 대상·프롬프트·평가 기준이 다를 수 있으므로 점수를 합산하거나 같은 조건의 성능 추이로 읽지 않는다.

## 공개 기준선 — v2.0.2

2026-11-09, 근거 선행 1회 호출 그래프의 v2.0.2가 12차(3라운드)에서 구조화 21/21·의미 189/189·내부 식별자 21/21 PASS를 기록해 공개 평가 기준선이 **v2.0.2**로 재고정됐다. 이 기준선은 C01–C07 7사례 세트에서만 유효하다. 합성 선행 EC2 격리 기록을 더한 C08·C09까지의 9사례 세트에서는 13–19차에 v2.0.2–v2.0.6을 측정했지만 비율 기준(사례마다 10회 중 8회 이상 PASS)을 충족한 판이 없다. 현재 배포 프롬프트는 **v2.0.5**이며 [prompt_snapshot.json](../prompt_snapshot.json)에 `candidate`, `quality_status` FAIL로 기록돼 있다(19차 81/90 — C05 5/10·C08 7/10 미달). 아래 12차와 13–19차에 조건과 한계를 적었다. 직전 기준선 v1.0.0의 내용은 다음과 같고 이력으로 보존한다.

### 이전 기준선 — v1.0.0

## 판정과 기준 변경을 읽는 방법

- **부분 비교와 전체 반복:** 1–3차는 각 입력 1회 관측이며, 4차부터 각 입력 3회로 측정했다. 부분 비교의 통과를 전체 7건 × 3회 기준선에 합산하지 않는다.
- **4차 판정 보류:** C06 세 출력은 생성·검토를 마쳤지만 `risk_reason`이 UNSURE여서 PENDING이다. 확정된 오답이나 생성 누락으로 바꾸어 쓰지 않는다.
- **5차 이후 기준 재검토:** 사용자 판단을 돕는 서비스 역할에 맞춰 후보 제시와 현재 적용 보류를 분리했다. 기존 출력 재검토에서는 제안 기준으로 21 PASS였으나 새 모델 호출은 없었다. 원래 19 PASS / 2 FAIL과 당시 무제안 지시 위반은 보존하며, 바뀐 기준은 v0.5.3의 새 6차 측정부터 적용했다.
- **7차 당시 통과와 추가 검사:** 구조화 21/21·기존 의미 기준 168/168은 당시 통과 기록이다. 이후 리뷰에서 확인한 내부 필드명 노출은 새 결정적 검사에서 21/21 FAIL이었다. 이 재분류를 원래 기록에 덮어쓰거나 새로운 모델 측정으로 세지 않는다.
- **최종 측정 범위:** 9차는 구조화 21/21·의미 기준 168/168·내부 식별자 검사 21/21을 통과했고 후보 20건·무제안 1건을 관측했다. 의미 평가는 assistant의 인용 기반 직접 검토이며, 세 줄을 함께 읽는 기준과 약한 표현의 한계는 아래 최종 측정의 한계에 남겼다.

### 최종 보완과 판정 근거

8차의 내부 필드명 노출(C02 2회차·C04 2회차·C06 1회차)과 C04 3회차의 중간→낮음 요약 모순은 9차에서 관측되지 않았다. 21건 모두 실제 재평가와 요약 등급이 일치했고 내부 식별자 검사도 통과했다.

C01–C03은 강한 반복과 높음, C04는 60회/10분·분당 6회와 중간, C05는 5회/10초·분당 30회와 중간을 설명했다. C06은 5회/1시간을 낮은 빈도의 반복으로, C07은 1회를 단발·낮음으로 유지했다. 후보와 무제안의 이유는 각각 관측과 함께 평가했다.

### 표현상의 한계와 미측정 범위

동결 rubric대로 요약 세 줄을 함께 읽었다. 다음 약점을 이유로 사후에 새로운 단일 문장 합격 기준을 추가하지 않았다.

- C04 1·3회차의 “모두 충족하지 않는”은 모호하다. 같은 문장의 횟수·빈도와 임계값을 함께 읽으면 횟수 조건만 충족함을 복원할 수 있어 PASS로 판정했다. 2회차는 이를 직접 명시한다.
- C03 1·2회차와 C04 2회차의 조치 문장은 관측 강도와의 연결을 앞의 진단 설명에 의존한다.
- C07 3회차의 “규칙이 없으므로 현재 적용은 보류”는 이유 연결이 약하다. 단발·낮은 근거 강도와 추가 실패 확인을 세 줄에서 함께 읽어 PASS로 판정했다. 후보 부재만으로 자동 통과시킨 것은 아니다.

이 결과는 합성 SSH 7사례의 관측이다. 무제안 1건으로 다른 입력의 무제안 품질을 일반화하지 않는다. 실제 탐지율·운영 침해·AWS 차단 효과, 선행 실행이 있는 분기, 저장·화면·사용자 종료 통합과 향후 출력의 무실패를 입증하지 않는다.

### 10차 — v2.0.0 (1라운드)
