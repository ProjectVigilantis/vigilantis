# v0.9.0 단가 전용 후보: 실행 계획

사용자가 1~3단계와 200호출 이하를 승인했다. 이 후보의 실행 한도는 180호출이다.
서비스 기본 그래프 편입과 v1.0.0 판정은 후속 단계다.

## 변경과 고정 조건

- AI는 현재·목표 시간당 단가와 추정 근거를 생성한다. AI 출력에서 `amount`를 제거했다.
- 단가는 숫자 문자열, 소수 최대 6자리 또는 null이며 모델 요청 스키마에 pattern을 전달한다.
- 서버가 단가의 형식·상한·대상 문맥·저장 가능성을 검증한 후
  `(현재 단가 - 목표 단가) × 730`을 계산하고 최종 금액만 센트 단위로 ROUND_HALF_UP한다.
- 저장·조회 결과는 기존 `amount + basis` 형태다. 계산 결과도 AI 추정 단가에 기반한 예상값이다.
- 모델은 gpt-5.6-luna / low, temperature 미지정, SDK·래퍼 재시도 0회다.
- 요약·추천 프롬프트, 기존 pair/table 후보, 고정 Golden 입력과 가격 평가 명세는 유지한다.
- 변경 축은 산술 책임, 숫자 출력 제약, 단가 전용 설명 지시의 묶음이다.
  결과가 달라져도 각 변경의 독립 효과나 모델 내부 원인까지 증명하지 않는다.

## 표본과 확대 조건

1. A1·A7·A11·A12·A14·A16 각 3회, 요약 → 추천 → 단가 추정: 최대 54호출.
2. 동일 후보에서 가격 허용 범위 이탈·계약/호출 오류 없이 입력 사실·후보 검사가 통과하면
   각 7회를 추가한다: 최대 126호출, 합계 180호출·60개 파이프라인.
3. 초기 18개는 최종 60개의 앞부분이다. 프롬프트·스키마·구현이 바뀌면 합산하지 않는다.
   초기 원자료·메타·채점은 `pilot/`에 보존하고 확대 실행에는 동일 후보 검사를 요구한다.
4. 최종 산출률 95%는 60개 중 최대 3개의 UNAVAILABLE를 허용한다. 초기 단계에서도
   이 최종 허용 개수를 넘으면 확대하지 않는다. 초기 통과를 최종 합격으로 부르지 않는다.
5. 가격/형식 실패는 초기 계획 표본 안에서 기록한다. 요청·전송·실행기 오류는 중단한다.
   실패 회차 재호출이나 미사용 호출 재배정은 하지 않는다.

## 평가

- [spec.json](../../spec.json) v0.2.0: 과대 +10% / 과소 -20%, 최소 절대 허용폭 1 USD,
  최종 산출률 95%, 형식·문맥 오류 0건. 단가 각각 ±10%는 별도 진단이다.
- 참조 단가는 평가에만 사용한다. AI 입력에 보내거나 서버에서 추정 단가를 보정하지 않는다.
- 산술·출력 형식·가격 정확도·설명 의미·저장/조회 증거를 구분한다.
- 요약 복원 판정자 호출은 이 실행에 포함하지 않는다. 자동 사실 검사와 공개 설명 진단을 남긴다.

## 비용과 기록

초기 54호출은 약 3~4분 / 0.02~0.05 USD, 추가 126호출은 약 7~9분 / 0.05~0.10 USD로
직전 사용량에서 추산했다. [공식 Luna 가격](https://developers.openai.com/api/docs/models/gpt-5.6-luna)은
입력 0.20 / 캐시 입력 0.02 / 출력 1.20 USD per million tokens로 실행 전에 확인했다.
보고 비용은 응답 usage에 근거한 추정이며 실제 청구액이 아니다.

단가 pattern은 [공식 Structured Outputs의 string 제약](https://developers.openai.com/api/docs/guides/structured-outputs)을
확인하고 실제 SDK mock transport 테스트로 요청에 포함되는 것을 확인했다. 외부 API의 실제
수용 여부는 승인된 초기 라운드에서 확인한다.

[승인](approval.json), [고정 입력·구현](preflight.json), [로컬 검증](preparation-verification.json),
[변경 전 기록](before.json), [실행기](run_round.py)를 함께 보존한다.

모델 원본 응답·거절된 원문·내부 추론·키는 보존하지 않는다. 수용된 구조화 출력,
호출 단계·usage·오류 필드/규칙으로 관찰 가능한 결과만 기록한다.
