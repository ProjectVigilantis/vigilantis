# v0.7.0 실제 3호출 진단 — 두 번째 실행

첫 실행은 worktree 키의 인증 문제로 중단했다. 사용자가 기본 체크아웃 키 사용과 최대 18호출의 새 라운드를 승인했다. 해당 키로 모델 메타데이터 조회가 성공한 뒤 실행한다.

프롬프트·스키마·입력·채점·순서는 [처음 확정한 계획](../20260915-v0.7.0-three-call-1/plan.md)과 같다.

- gpt-5.6-luna / low, temperature 미지정, A1·A11 각 3회.
- 요약 → 추천 전용 → 절감 예상 전용. 최대 18호출, 재시도 없음, 요청 timeout 30초.
- A1/1 → A11/1 → A11/2 → A1/2 → A1/3 → A11/3 순서.
- 예상 1~2분·$0.015~$0.03. 청구액·하드 비용 상한이 아닌 usage 기반 추정이다.
- 품질 실패는 정한 6회에서 수집한다. 통신·요청 오류 또는 예상하지 못한 실행기 오류에서는 중단한다.
- 호출 사용량·단계 오류와 가격 오차·계약 거부를 따로 기록한다. 생략된 호출은 재배정하지 않는다.
- 첫 실행 기록은 그대로 보존한다. 후속 실행은 이 디렉터리에 새로 기록한다.

인증은 사용자가 지정한 기본 체크아웃의 `.env` 키를 메모리에서 읽어 공식 `https://api.openai.com/v1`에 사용한다. 키 값을 실험 산출물에 쓰지 않는다. 모델 메타데이터 조회는 유료 생성 0회였고 `gpt-5.6-luna` 접근이 확인됐다.
