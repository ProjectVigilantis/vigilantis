# v0.7.0 실제 3호출 진단 — 6회 실행, 4회 가격 통과

**요약 → 추천 → 절감 예상의 실제 3호출을 6회 모두 실행했다. 가격 기준은 4회 통과·2회 미달, 서버의 절감 계약 거부는 0회다. 실패한 두 건은 계산이 맞지만 단가가 참조와 달랐다.**

이번 결과는 3호출의 작동·사용량·실패 유형을 보여 준다. 현재 프롬프트로 가격 정확도 기준을 충족했다는 결과는 아니다. 서비스 3호출 채택과 승인 기준선 갱신은 하지 않았다.

## 실행 범위

- 모델: `gpt-5.6-luna`, reasoning `low`, temperature 미지정. 응답 model 값은 모두 같은 별칭이었다.
- A1·A11 각 3회. 매 실행마다 요약을 새로 만들고 그 요약으로 추천한 뒤 가격 전용 호출을 했다.
- 총 18호출: 요약 6·추천 6·절감 예상 6. 재시도·생략·호출 오류 0회.
- 총 61.000초. 3호출 실행당 평균 10.123초, 범위 8.994~11.157초.
- 사용량: 입력 31,900·출력 4,257토큰. 입력 중 캐시 18,200토큰. usage 누락 0회.
- 캐시 할인 미적용 비용 추정: **$0.0114884**, 실행당 약 $0.001915. 입력 $0.20/1M·출력 $1.20/1M의 [공식 모델 단가](https://developers.openai.com/api/docs/models/gpt-5.6-luna)를 적용한 계산이며 청구액은 아니다.

처음 실행은 worktree 키의 인증 문제로 중단됐다. 사용자에게 기본 체크아웃 키 사용과 새 18호출 승인을 받은 뒤 모델 접근을 확인하고 이번 라운드를 실행했다. [첫 중단 기록](../20260915-v0.7.0-three-call-1/report.md)은 이 결과와 별도로 보존한다.

### 두 실패에서 확인한 것

**A1/1:** `t3.xlarge`를 참조 $0.208000보다 10.77% 높은 $0.230400으로 추정했다. `t3.medium`은 $0.052800으로 참조보다 1.54% 높았다. 그 차액에 730시간을 곱한 $129.65는 산술적으로 맞지만 월 참조보다 13.85% 높다.

**A11/2:** `t3.large` $0.092000과 `t3.small` $0.023000 모두 참조보다 11.54% 낮았다. 계산된 $50.37 역시 같은 비율로 낮다. 두 단가 사이의 비율이 일관돼도 실제 가격 정확도는 별도로 실패할 수 있다.

두 건 모두 대상·리전·사양·가정·수식·소수 자리 계약은 통과했다. 공개 근거도 모델 지식에 따른 추정이라고 명시했다. 따라서 이번 실패를 JSON 형식이나 산술 계산 문제로 분류하지 않는다. 모델이 왜 해당 단가를 선택했는지는 공개 출력만으로 확정할 수 없다.

- 6개 실행 모두 예상 RIGHTSIZING 후보 하나를 반환했다. 대상·다운사이징 사양·근거 ID가 입력과 일치했다.
- 18개 요약 문장에서 식별자·숫자·사양의 입력 밖 인용은 검출되지 않았다.
- 6개 observation 모두 입력 근거를 인용했다.
- 구조화 값 되읽기 근사는 3개 실행에서 `COST_CANDIDATE`를 검출했다: A11/2 첫 줄, A1/3 첫 줄, A11/3 둘째 줄.
- 6개 절감 예상 모두 서버 수용 검증을 통과했다. `savings_diagnostics`는 모두 비어 있다.

### 공개 문장 검토 — 합격 게이트와 별도인 진단

6개 산출 근거를 모두 읽었다. 리전·Linux·공유 테넌시·온디맨드·730시간·컴퓨팅 범위·모델 지식 출처는 구조화 값과 맞았고, 공개 설명의 단가와 월 금액도 구조화 값과 같았다. 이 설명의 내부 일치가 AWS 단가 정확도를 보장하지는 않는다.

A1/1의 진단은 “유휴에 가까운 상태로 확정된다”라고 썼다. 입력은 낮은 사용률과 `COST_CANDIDATE` 판정이며 자산이 유휴라고 확정한 사실은 없다. [기존 요약 결함 목록](../../../summary_defects.md)의 단정·추정 분리 관점에서 추가 검토할 표현이다. 이 검토를 전문가 판정이나 기존 판정자의 복원 대조 통과로 취급하지 않는다.

이번 실행에는 LLM 판정자 호출이나 승인 요약 판과의 짝 비교가 없다. 자동 사실 검사가 통과했다고 요약 기준선까지 승인한 결과로 확대하지 않는다.
