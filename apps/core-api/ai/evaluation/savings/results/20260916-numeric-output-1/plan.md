# 후보 B — 상태·두 단가만 생성하는 충분성 평가

2026-09-16. [설계의 B](../../plans/20260916-output-simplification.md)에 대한 실행 계획이다.
사용자는 최대 80회 유료 호출을 승인했고, A의 2회 실행 결과를 확인한 뒤 B 최대 60회 제안에 “진행해”라고 지시했다.
이 라운드는 **B 한 열, 최대 60회**다. A를 포함한 누적 상한은 62회이며 사용자 한도 80회를 넘지 않는다.

## 변경과 고정 조건

- A의 출력에서 `explanation`을 제거한다. 필드 순서는 `status`, `current_hourly_rate`, `target_hourly_rate`다.
- 역할·스키마 설명에서 근거 생성 문구를 제거한다. 한국어 설명·공개 코드 표현·미산출 사유 문장 작성 지시를 제거한다.
  월 계산은 서버가 담당한다는 지시는 남기고 설명을 작성하라는 부분만 제거한다.
- 단가 식별 지시, 숫자 pattern·범위, Linux/Shared/OnDemand 가정, Golden 입력, 참조 스냅샷, 채점 명세 v0.2.0은 고정한다.
- 모델은 `gpt-5.6-luna`, reasoning `low`, temperature 미지정이다.
- 서버는 평가 결과의 설명을 템플릿으로 작성한다. 각 결과에 `explanation_source=SERVER_TEMPLATE`를 기록한다.
  이 설명이 모델의 문맥 해석·단가 기억을 입증하는 것은 아니다. 기존 서비스의 AI 설명 계약 변경은 이번에 적용하지 않는다.
- 실제 SDK 요청을 A와 대조해 입력 동일성과 설명 제거에 필요한 차이만 있는지 확인한다. 실행 때도 전송 직전 지문을 확인한다.

## 표본과 중단

- A1·A7·A11·A12·A14·A16 × 각 10회. 반복을 바깥 순서로 두고 홀수는 위 순서, 짝수는 역순이다.
- 각 회차는 단가 호출 1회다. 요약·추천·판정자 호출은 없다. 별도 온라인 대조군도 호출하지 않는다.
- 6사례에는 가격 조건 두 종류만 있다. 충분성 확인이며 A보다 우월하다는 인과 효과나 일반 실패율을 추정하지 않는다.
- 전체 60회 완료, ESTIMATED 최소 57건, 가격 이탈·출력 계약 오류 0건이어야 통과한다.
- 절감액 과대 +10%·과소 −20%, 최소 절대 허용폭 1 USD, 센트 HALF_UP 경계를 유지한다.
- **첫 가격 이탈·출력 계약 오류 또는 네 번째 UNAVAILABLE에서 즉시 중단한다.**
- 호출 장애·실행기 오류는 미완료로 남기고 중단한다. SDK 재시도 0, 래퍼 시도 1회, timeout 30초다.
- STARTED를 요청 전에 기록한다. 재개·재시도·실패 표본 교체·추가 표본은 없다.
- 이전 A 장부의 지문·2회 사용량을 고정하고, 실행 전에 남은 사용자 한도를 검사한다.

## 비용·시간과 전송

최대 60회 기준 **0.02~0.06 USD, 약 4~7분**을 예상한다. 조기 중단 시 미사용 호출은 발생하지 않는다.
A의 두 응답 평균을 그대로 60회로 환산하면 usage 비용 0.033264 USD, 요청 시간 약 338초다.
B의 출력 축소가 비용·시간을 얼마나 바꿀지는 실행 전 확정할 수 없어 여유 범위를 사용한다.
예상치는 보장 상한이 아니며 호출 수 상한은 60회다.

[공식 Luna 단가](https://developers.openai.com/api/docs/models/gpt-5.6-luna)를 2026-09-16 다시 확인했다.
100만 토큰당 입력 0.20 / 캐시 입력 0.02 / 출력 1.20 USD다. 캐시 쓰기는 비캐시 입력의 1.25배다.
SDK usage가 별도 보고하지 않는 항목과 실제 청구액은 미확인으로 남긴다.

목적지는 `https://api.openai.com/v1/chat/completions`다. 이전에 확인한 공개 Golden 더미 입력과 같은 여섯 과금 문맥을 전송한다.
더미 ARN의 계정 123456789012는 기존 정책대로 유지된다. ARN이 마스킹됐다고 표시하지 않는다.
리전·현재/목표 타입·통화·기간·과금 가정 외에 태그·메모·참조 가격을 입력에 추가하지 않는다.
기본 체크아웃의 기존 승인된 `.env` 키는 승인·중복 실행 검사 뒤 읽고 OpenAI 인증 헤더에만 사용한다.
원문 응답·내부 추론·키를 저장하지 않고 수용된 구조화 결과·진단 위치/규칙·usage·시간을 기록한다.
