# #347 B 서비스 연결 검증 — 2026-09-16

B의 숫자 전용 출력을 서비스에 연결했다. 실제 모델로 6사례의 요약·추천 → 가드레일 → 단가 추정
→ PostgreSQL 저장 → 새 앱 조회가 모두 통과했다. 이번 검증은 18호출이며, 승인된 누적 한도 **80/80회**를 사용했다.
현재 로컬 구현은 v0.10.0이다. Issue 전체 완료·최신 dev 통합·실제 AWS 조치 실행을 뜻하지 않는다.

## 구현과 계약

- 서비스 Dispatcher가 `ai.rate_estimator`를 사용한다. 모델 출력은 `status`와 현재·목표 시간당 단가 두 개다.
  실험 B의 프롬프트와 SDK 요청 스키마를 유지했고, 실험 모듈을 운영 경로에서 import하지 않는다.
- 서버가 분석 시점 자산·목표 타입·730시간 비교 가정을 결합하고 Decimal HALF_UP으로 월 절감액을 계산한다.
  설명도 서버가 작성하며 `basis.explanation_source=SERVER_TEMPLATE`을 명시해 저장한다.
- 단가의 `pricing_source=MODEL_KNOWLEDGE`와 설명의 출처를 구분한다. 이전 JSONB에 설명 출처가 없으면
  `MODEL_GENERATED`로 읽는다. 과거 행의 설명을 다시 작성하거나 출처를 재분류하지 않는다.
- 요약·추천 2호출 후 모든 후보의 가드레일을 거치고, PASS RIGHTSIZING에만 단가 1호출을 추가한다.
  모델·AWS 호출 중 DB 트랜잭션을 닫고, 추정 실패에도 실행 가능한 후보와 PASS 결과를 보존한다.
- API는 저장된 추정값을 반환한다. 조회 시 재추정하지 않으며 추정값은 실행 명령과 분리한다.

필드별 소유자·상태·호환성과 예시는 [저장·조회 계약](../../contract.md)에 있다.
서비스 절감 추정 지문은 `b52d6a31b0b7d0a632c8b61a58c6ad7de559ee2d8c6bbc0bb163f7db30e5bbc2`다.
FinOps 요약은 승인 v2 지문 `1e2e5c45cd1b1d250ebf371ba65699827bf3c42f88f6d77080515a07c22e1cc7`을 유지했다.
이번 실행에서 요약의 의미 품질을 별도 judge로 재평가하지 않았다.
