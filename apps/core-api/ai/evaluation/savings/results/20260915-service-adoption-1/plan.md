# 서비스 편입 후보 v0.9.1 — 최종 검증 계획

## 구현 범위

- 실제 FinOps LangGraph에 요약 → 추천 → 단가 추정의 3호출을 연결했다.
- 단가 추정·서버 계산 방식은 v0.9.0을 유지한다. 요약의 관측·추정 구분과 공개 문장의 내부 필드명 표현만 보완했다.
- 새 문구는 새 후보이므로 v0.9.0의 60/60 결과를 새 문구의 계측으로 대신하지 않는다.
- 후보 계약이 유효한 RIGHTSIZING에만 단가를 묻고, 단가 호출 실패 시 후보는 보존하며 추정은 INVALID/MISSING_ESTIMATE로 남긴다.
- 기존 실험의 요청·출력 경로는 evaluation/savings/legacy.py로 분리했다.

## 추가 모델 호출 — 최대 540호출 승인, 단계별 실행

작업 트리와 기본 체크아웃에서 승인 v2의 60회 원자료를 찾지 못했다.
승인 당시 Git 코드의 프롬프트 지문이 v2 스냅샷과 일치함을 확인했으므로 그 코드로 비교 자료를 재생성한다.

| 단계 | 열과 반복 | 최대 호출 |
| --- | --- | ---: |
| 기존 기준선 재생성 | 승인 v2 × 6건 × 10회, 실행당 2호출 | 120 |
| 서비스 후보 생성 | v0.9.1 × 6건 × 10회, 실행당 3호출 | 180 |
| 기존·새 요약 판정 | 120개 출력에 복원·문장 진단 각 1호출 | 240 |
| 합계 | 생성 2개 열, 판정자 1개 설정 | **540** |

모두 gpt-5.6-luna / low, temperature 미지정, SDK·래퍼 재시도 0회다.
이전 라운드의 200호출 승인을 이 계획에 재사용하지 않는다.
2026-09-15 사용자의 “최대 540호출 추가 승인”을 [approval.json](approval.json)에 기록했다.
실제 단계 상태·호출 수·usage는 실행 중 생성되는 [metadata.json](metadata.json)을 기준으로 확인한다.
예상 비용은 **0.30~0.60 USD**, 소요 시간은 **25~40분**이다.
직전 생성 라운드의 토큰 사용량과 판정 요청 규모로 추산했으며 실제 청구액은 아니다.
[공식 Luna 단가](https://developers.openai.com/api/docs/models/gpt-5.6-luna)는
입력 0.20 / 캐시 입력 0.02 / 출력 1.20 USD per million tokens를 적용한다.

승인 v2의 Git 참조는 3e482a4aed9bdae3308d1eabc58676963e1265c2이며
프롬프트 지문은 1e2e5c45cd1b1d250ebf371ba65699827bf3c42f88f6d77080515a07c22e1cc7이다.
고정 입력·가격 명세와 각 단계의 실제 소스 지문은 preflight.json에 둔다.

## 판정과 중단

- 절감액 기준은 기존 spec.json v0.2.0: 과대 +10% / 과소 −20%, 최소 허용폭 1 USD, 센트 반올림, 산출률 95%.
- 22회의 단가 진단은 전부 낮게 추정한 방향이었고 절감액 기준에 통과했다. 이를 새 실패 조건으로 삼지 않는다.
- 후보 생성 완료 뒤 가격 기준이 미달하면 판정 단계로 확대하지 않는다. 실패 회차 재호출·교체·예산 재배정은 없다.
- 요청·전송 오류는 해당 단계에서 중단하고 호출 단계·오류 종류·usage만 기록한다.
- 요약의 계약 오류·빈 후보·입력 사실 오류·실행값 흔들림과 복원 결과를 승인 기준과 대조한다.
- 문장 진단 플래그를 자동 실패로 바꾸지 않고 실제 공개 문장과 대조한다.
- 최종 문구의 생성·판정이 통과한 뒤에만 승인 스냅샷과 PR 버전 v1.0.0을 반영한다.

## 실행 경계

[run_validation.py](run_validation.py)의 기본 실행은 네트워크 없는 사전 확인이다.
실행에는 현재 preflight.json 지문과 최대 호출 수가 일치하는 사용자 승인 기록이 필요하다.
승인·소스 동일성·단계 순서·중복 실행·호출 상한을 검사한 후 기존에 승인된 기본 체크아웃 키를 사용한다.

기존 원자료와 판정은 보존한다. 새 결과·호출 usage·판정은 이 폴더에 저장한다.
공급자 원본 응답, 키, 내부 CoT, 거절된 원문은 저장하지 않는다.
