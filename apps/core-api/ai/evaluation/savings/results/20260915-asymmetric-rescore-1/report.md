# 절감액 비대칭 허용 기준 적용과 기존 결과 재채점

**절감액을 높게 잡는 쪽은 10%, 낮게 잡는 쪽은 20%까지 허용하도록 바꿨다. v0.8.0 비교의 기존 방식은 6/6 통과, 가격표 방식은 3/6 통과·리전 오류 3건이다. 추가 모델 호출은 0회다.**

2026-09-15 사용자 결정: “엄격한 방향을 10%보다 더 낮추는건 별로고, 널널해도 되는 쪽을 20%로 풀어주자.” 직전 대화에서 정리한 표시 목적에 따라 **절감액의 과대·과소 추정**에 적용했다. 단가 자체의 정확도는 별도 진단으로 남긴다.

## 변경한 기준

| 항목 | 실행 당시 v1 | 현재 v0.2.0 |
| --- | --- | --- |
| 절감액 과대 추정 | 최대 10% | **10% 유지** |
| 절감액 과소 추정 | 최대 10% | **20%까지 허용** |
| 작은 금액의 최소 허용 오차 | $1 | 유지 |
| 전후 단가 정확도 | 각각 ±10%, 절감액 합격에 포함 | 각각 ±10%와 방향을 진단으로 기록, 절감액 합격과 분리 |
| 산술·서버 문맥·가정·계약 오류 | 거부 | 유지 |
| 미산출·누락·호출 실패 | 분모 유지 | 유지 |
| 전체 기준선 | 6건 × 10회, 95% 이상 산출, 허용 밖 추정·계약 오류 없음 | 유지 |

현재 명세는 [spec.json](../../spec.json), 이전 명세는 [spec-v1.json](../../spec-v1.json)이다. 프롬프트 판은 그대로이며 새 번호는 평가 명세·채점기의 판이다. 실행 당시 보고서·계획·원자료·채점 결과 50개는 변경하지 않았다.

### 센트 반올림 경계

참조 절감액 $56.94에서 −20% 경계는 $45.552, +10% 경계는 $62.634다. 출력이 소수 둘째 자리 금액이므로 양 끝을 같은 규칙으로 반올림해 **$45.55~$62.63**을 허용한다.

따라서 $45.55를 소수점 이하 반올림 차이로 20% 초과 처리하지 않는다. $45.54나 $62.64는 허용 밖이다. 센트 반올림은 판정 경계에 적용하며 모델 출력·단가·산출 금액은 바꾸지 않는다.

## 주요 결과

| 저장된 실행 | 이전 판정 | 새 판정 | 남은 실패 |
| --- | --- | --- | --- |
| v0.8.0 기존 pair, 6회 | PASS 5·가격 오차 1 | **PASS 6** | 없음. 가격 전용 6회 진단의 통과 |
| v0.8.0 가격표, 6회 | PASS 1·가격 오차 2·계약 거부 3 | **PASS 3·계약 거부 3** | 리전 불일치 3건 |
| v0.7.0 실제 3호출, 6회 | PASS 4·가격 오차 2 | **PASS 5·가격 오차 1** | A1/1 절감액 과대 추정 +13.85% |

v0.8.0 A11의 $45.55는 참조 $56.94보다 보수적으로 잡은 값이므로 새 절감액 기준을 통과한다. 그 근거 단가는 참조보다 20% 낮고 단가 정확도 진단에는 여전히 미달로 남는다. 절감액 PASS를 조치 후 비용이나 실제 청구액이 정확하다는 뜻으로 읽지 않는다.

v0.7.0 A1/1의 예상 $129.65는 참조 $113.88보다 13.85% 높다. 위험한 방향의 10%를 유지했으므로 계속 실패한다. 리전 불일치·잘못된 산술·누락을 가격 허용 범위로 수용하지 않았다.

새 통과 수는 **평가 기준 변경에 따른 재분류**다. 모델 출력의 개선이나 새 실행 결과가 아니다. v0.8.0 가격표는 여전히 6/6 조건에 미달하고, 전체 60회 기준선·요약 회귀도 새로 통과한 것이 아니다.

[summary.json](summary.json)에 결과별 원자료 지문과 새 채점 파일 경로를 남겼다. 새 판정은 이 폴더의 `scored/` 아래에만 썼다. 새 가격 명세로 과거 생성 실행기를 다시 돌리지 않았다.

## 검증

- 과대 +10%·과소 −20% 경계, 경계 밖 1센트, 금액 단위 반올림, 기존 $1 최소 허용, 단가 진단과 절감액 판정의 분리, 이전 대칭 기준 재현을 확인했다.
- 관련 pytest: **57 통과·0 실패·0 skip·2,063 deselected**, 43.47초. 평가·가격표·3호출 연결을 대상으로 했으며 전체 CI 실행은 아니다.
- 기존 10개 채점 결과를 보존한 v1 명세로 재현했고, 이전 산출물 50개 지문이 수정 전과 일치했다.
- 모델·프롬프트·입력·참조 단가와 출력은 그대로다. 추가 생성 비용 0, 추가 모델 호출 0회다.

재현 명령은 [rescore.py](rescore.py) 실행이다. 이 파일은 보존한 입력과 명세를 읽어 채점 파일만 쓴다.
