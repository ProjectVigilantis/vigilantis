## 변경과 비교 범위

추천 프롬프트에 리전·인스턴스 타입·과금 조건에 맞는 두 단가를 먼저 식별하고 월 차액을 계산하는 순서를 명시했다.
[v0.3.0](../20260915-v0.3.0-probe-1/report.md)과 모델 설정, 원천 입력 세트, 출력 스키마, 가격 참조와 채점 기준은 같다.
참조 단가는 평가에만 사용했다. 요약 노드는 같은 프롬프트로 새로 호출하므로 추천 노드가 받는 요약 문장은 회차마다 달라질 수 있다.
각 버전·케이스가 1회뿐이므로 관측된 차이를 프롬프트의 개선·악화 효과로 확정하지 않는다.

## 판정과 후속 범위

A11의 월 금액 오차는 20.00%에서 1.55%로 줄었고 A1은 9.23%에서 20.00%로 늘었다.
두 예비 라운드 모두 한 건이 가격 기준을 초과했으므로 v0.4.0을 통과한 개선안으로 채택할 수 없다.

`scored.json`의 `complete=false`는 전체 6건 × 10회가 아닌 예비 실행이라는 뜻이다.
A1의 `PRICE_DEVIATION`은 반복 수 부족과 별개의 실제 가격 오류다. 승인 스냅샷과 품질 기준선은 보류한다.

후속 개선은 Luna/low를 유지하고 단가 선택을 대상으로 한다. 현재 결과만으로 모델 지식의 어떤 가격이 대입됐는지는 확정하지 않았다.
다음 개선안과 별도 실행 범위를 정한 뒤 재계측하며, 현재 라운드를 추가 반복하거나 전체 60회로 확대하지 않았다.
