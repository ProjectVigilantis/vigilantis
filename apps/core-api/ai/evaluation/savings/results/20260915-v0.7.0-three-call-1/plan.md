# v0.7.0 실제 3호출 진단 계획 — 실행 전 확정 기록

> 실행 후 상태: 사용자의 라운드·외부 전송 승인 후 첫 요약 요청에서 인증 문제로 중단했다. 아래는 실행 전 확정한 계획이며, 실제 결과는 [report.md](report.md)에 기록했다.

v0.6.0 가격 전용 진단의 첫 4건이 통과한 관찰을 이어서, 요약 → 추천 → 절감 예상의 연속 호출을 시험한다.
이번 목적은 채택 전 진단이며 서비스 기본 그래프는 v0.5.0의 2호출 경로를 유지한다.

## 변경과 고정

- 요약: 기존 요약 노드·프롬프트로 매 실행 새로 생성한다.
- 추천: 기존 추천 노드의 입력·계약 검증을 재사용한다. 실제 모델 요청에서 가격 지시, `savings_context`, 절감 예상 출력 필드를 뺀다.
- 절감 예상: 유효한 RIGHTSIZING 후보가 나온 경우 v0.6.0과 같은 한국어 가격 지시·내부 스키마·가격 문맥으로 세 번째 호출을 한다. 최종 후보와 금액·근거를 합친다.
- 수용 실패는 필드 위치와 검증 규칙을 기록한다. 원래 거부 값·예외 메시지·프롬프트 전문·제공자 원본 응답은 보존하지 않는다.
- Luna/low, temperature 미지정, 가격 참조·10% 오차·산출률 기준을 유지한다. 평가 정답 단가를 모델 입력에 넣지 않는다.
- 가격 지시의 지문은 v0.6.0과 동일하다. 새 v0.7.0 지문은 세 호출의 지시·출력 스키마 구성을 식별한다.

## 실행 규모

| 항목 | 계획 |
| --- | --- |
| 조합 수 | 1열 — gpt-5.6-luna / low, 3호출 구성 |
| 사례·반복 | A1·A11 각각 3회, 총 6개 실행 |
| 순서 | A1/1 → A11/1 → A11/2 → A1/2 → A1/3 → A11/3 |
| 유료 호출 상한 | 18회 — 정상 실행마다 요약·추천·절감 각 1회 |
| 재시도 | 래퍼 최대 시도 1, SDK 재시도 0 |
| 요청 timeout | 30초 |
| 소요 예상 | 약 1~2분. timeout이 발생하면 해당 시점에 중단 |
| 비용 예상 | 약 $0.015~$0.03, 캐시 할인 미적용 추정. 청구액·하드 한도 아님 |

비용의 기준은 [공식 Luna 단가](https://developers.openai.com/api/docs/models/gpt-5.6-luna)의 입력 $0.20/1M·출력 $1.20/1M과 기존 사용량이다.
v0.4.0의 2호출 실행 평균 비용 $0.0017663에 v0.6.0 가격 전용 호출 평균 $0.00063932를 더해 6회로 환산하면 $0.01443372다.
새 추천 전용의 실제 usage는 아직 없으므로 약 $0.015를 중심으로 $0.03까지 여유를 둔 추정 범위를 제시한다. 입력·출력 토큰 길이에 따라 달라진다.

## 중단과 판정

- 이전 라운드의 첫 실패 중단과 달리, 이번에는 **실패 빈도와 원인 분류를 위해 정한 6개 실행을 채운다.** 가격 오차·서버 수용 거부·후보 오류·NO_PROPOSAL은 결과로 보존한다.
- 통신·요청 오류, 예상하지 못한 실행기 오류는 즉시 중단한다. 응답 파싱 실패는 단계·사용량 가용 여부를 기록하고 해당 실행을 실패로 센다.
- 요약·추천이 실패하거나 유효한 RIGHTSIZING 후보가 없으면 그 실행의 후속 호출을 생략한다. 생략된 호출을 다른 사례에 추가하거나 반복 상한을 늘리지 않는다.
- 오류가 있다고 기준을 완화하지 않는다. 이번에도 계약 거부·가격 오류가 있으면 기준 미충족이다. 실패를 끝까지 수집하는 실행 정책과 품질 합격 기준은 별개다.
- 기존 `score_report`로 후보·절감 예상 결과를 채점한다. 모델 호출 오류는 `calls[].error_phase`와 단계로 별도 집계해 서버 수용 거부와 구분한다.
- 각 호출·전체 실행의 시간·usage, 새 요약·최종 후보·추정값·수용 진단을 남긴다. 각 3줄 요약의 자동 사실 검사와 공개 근거도 확인한다.
- 전체 6사례 ×10회 기준선이나 승인 판과의 요약 짝 비교는 이번 범위가 아니다. 이 라운드만으로 서비스 채택·승인 스냅샷 갱신을 결정하지 않는다.

## 실행 전 확인

[preflight.json](preflight.json)에 입력·명세·구현·프롬프트 지문과 아래 결과를 기록했다.

- 실제 OpenAI SDK + mock transport 3요청, 유료 호출 0회.
- 응답 스키마 순서: `EvidenceSummaryOutput` → `CandidateProposalOutput` → `ProposedSavingsEstimate`.
- 새 요약이 추천 입력에 전달되고, 추천 요청에는 가격 업무·필드가 없으며, 세 번째 요청은 동일 가격 문맥만 받는 것을 확인했다.
- 계약 거부 진단에서 값·예외 메시지가 빠지고 필드·규칙이 최종 실험 기록에 남는 것을 확인했다.
- 관련 pytest: 104 통과·1 실패·1,991 deselected·0 skip·0 환경 오류, 43.94초. 실패는 기존 승인 스냅샷 v2와 런타임 v0.5.0 불일치다. 스냅샷은 갱신하지 않았다.
- 과거 채점 파일 6개 재계산 결과가 모두 일치했다.

작성 당시에는 위 규모·비용·시간에 대한 라운드 승인 대기 상태였다. `preflight.json`은 그 실행 전 검증 기록으로 보존한다.
